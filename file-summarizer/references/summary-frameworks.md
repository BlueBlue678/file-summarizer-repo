# 提炼重点与简化描述方法论

## 四要素筛选法（提炼重点）

对每一段内容依次判断并归类：

1. **结论/观点**：作者的核心主张、最终判断。
2. **关键数据**：数字、日期、金额、百分比、指标、人名机构名。
3. **决策与行动项**：已定决策、待办、负责人、截止日期。
4. **风险与问题**：明确指出的限制、缺陷、待解决事项。

保留标准：若删除这条信息会改变读者对文件的理解或决策，则保留；否则丢弃。

## 简化描述七原则

1. **拆长句**：一句一个意思。
2. **删冗余**：去掉套话、重复、过度限定。
3. **换通俗**：术语改白话（首次保留原词加注）。
4. **用主动**：避免"进行了……的处理"式空话。
5. **保数据**：数字、单位、专名不简化掉。
6. **控长度**：每条 1–2 行。
7. **不改写结论**：只变表达，不变原意。

## 各类型文件的重点清单

### 报告 / 研究文档
研究问题与结论 · 核心数据与方法 · 建议与行动项 · 局限性

### 合同 / 法律文件
签约主体与生效日期 · 权利义务核心条款 · 金额/期限/违约责任 · 风险与例外条款

### 会议记录
主题与时间 · 决议事项 · 行动项（负责人+截止日期） · 遗留问题

### 财报 / 数据表格
核心指标与同比/环比 · 异常波动项 · 趋势结论 · 数据口径说明

### 技术文档 / 代码
功能与用途 · 架构/接口关键点 · 使用方式 · 依赖与限制

### 新闻 / 文章
事件核心（5W1H） · 关键数据与引述 · 影响与后续

### 邮件 / 沟通消息
发件人与目的 · 请求/决定 · 时间节点 · 需回复事项

## 输出模板

### 标准模板
```
## 一句话概括
<文件是什么 + 核心结论>

## 关键要点
- 要点一（1–2 行）
- 要点二
- 要点三

## 重要数据
- 数据/指标 1
- 数据/指标 2

## 行动项与风险（如有）
- 待办 / 风险点
```

### 极简模板
一句话概括 + 3–5 条要点，适合快速浏览。

### 详细模板
标准模板 + 分章节展开 + 关键原文引用，适合需要追溯的场景。

## 端到端示例

**原始文本（节选）**：
> 本项目在报告期内共计实现营业收入约 1,250 万元，较上年同期增长 23.5%，主要得益于核心产品在华东区域的渠道拓展以及新客户订单的增加。但同时应当注意到，原材料成本同比上升了 8%，对公司毛利率造成一定压力。下一阶段，公司计划进一步优化供应链，并于第四季度完成两条新产线的投产工作。

**标准摘要输出**：

```
## 一句话概括
本期营收 1,250 万元、同比增 23.5%，但成本上升挤压毛利，下一步靠供应链优化与新产线应对。

## 关键要点
- 营收增长主要来自华东渠道拓展和新客户订单。
- 原材料成本同比上升 8%，毛利率承压。
- 计划优化供应链，并在第四季度投产两条新产线。

## 重要数据
- 营业收入：约 1,250 万元
- 同比增速：+23.5%
- 原材料成本：同比 +8%

## 行动项与风险
- 行动项：优化供应链；第四季度投产两条新产线。
- 风险：原材料涨价持续压缩毛利。
```

该示例体现：长句拆短、去除冗余修饰、保留全部关键数据、用要点式呈现。
